# Змейка — проект «Изгиб Питона»

Классическая игра «Змейка» на Python и Pygame. Реализация использует
объектно-ориентированный подход: классы `Apple` и `Snake` наследуются
от общего класса `GameObject`.

Проект основан на [шаблоне Яндекс Практикума](https://github.com/yandex-praktikum/the_snake).

## Технологии

- Python 3.12.
- Pygame 2.5.2 — игровое окно, события и отрисовка.
- Pytest 7.1.3 — автоматические тесты заготовки.
- Flake8 5.0.4 с плагинами — проверка оформления кода и docstring.

Все зависимости и их версии указаны в `requirements.txt`.

## Подготовка окружения

Команды ниже рассчитаны на Windows и терминал Git Bash. Перейдите
в корневую папку проекта, где находятся `the_snake.py` и `requirements.txt`.

Создайте виртуальное окружение с Python 3.12:

```bash
py -3.12 -m venv venv
```

Активируйте его:

```bash
source venv/Scripts/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Если окружение уже создано и зависимости установлены, достаточно
активировать его перед запуском игры или проверок.

## Запуск

```bash
python the_snake.py
```

## Управление и правила

| Действие | Управление |
| --- | --- |
| Поворот вверх | Стрелка вверх |
| Поворот вниз | Стрелка вниз |
| Поворот влево | Стрелка влево |
| Поворот вправо | Стрелка вправо |
| Завершение игры | Закрытие игрового окна |

- Поле имеет размер 640 × 480 пикселей, ячейка — 20 × 20 пикселей.
- При первом запуске змейка состоит из одной ячейки в центре поля
  и движется вправо.
- Прямой разворот в противоположную сторону запрещён.
- Съеденное яблоко увеличивает змейку на один сегмент. Новое яблоко
  появляется в свободной ячейке.
- Выход за край поля переносит змейку к противоположному краю.
- Столкновение с собственным телом возвращает змейку в центр
  с длиной 1 и случайным направлением движения.
- Если змейка заполняет всё поле, начинается новый раунд.

## Проверки

Запускайте команды из корневой папки проекта с активным окружением.

Проверка оформления кода:

```bash
python -m flake8
```

Автоматические тесты:

```bash
python -m pytest
```

При контрольном прогоне реализации Flake8 завершился без замечаний,
все 37 тестов заготовки прошли успешно. Вручную проверены управление,
рост после поедания яблока, переходы через края, перезапуск после
столкновения и завершение игры при закрытии окна.
